# Todo List React App

Ứng dụng quản lý công việc được xây dựng bằng React.

## Tính năng

- ✅ Thêm công việc mới
- ✏️ Sửa công việc
- 🗑️ Xóa công việc
- ☑️ Đánh dấu hoàn thành
- 📊 Hiển thị số lượng công việc đã hoàn thành
- 🎉 Thông báo khi hoàn thành tất cả công việc

## Cài đặt

1. Cài đặt dependencies:
```bash
npm install
```

## Chạy ứng dụng

### Development mode
```bash
npm run dev
```
Ứng dụng sẽ chạy tại `http://localhost:3000`

### Build cho production
```bash
npm run build
```
File build sẽ được tạo trong thư mục `dist/`

### Preview build
```bash
npm run preview
```

## Cấu trúc dự án

```
├── App.js              # Component React chính
├── index.js            # Entry point
├── index.html          # HTML template
├── todo-list.css       # Styles
├── package.json        # Dependencies và scripts
└── vite.config.js      # Vite configuration
```

## Công nghệ sử dụng

- React 18
- Vite (Build tool)
- CSS3
